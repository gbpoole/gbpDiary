---
name: minutes-export
description: Read before working on minutes/notes export to markdown, zip, or PDF — MinutesExport, NotePDFSegments, ExportPalette, MinutesExportView, the dataWithPDF renderer, and the three rejected renderers.
---

**Download minutes** (macOS) exports a composed markdown — meeting header (title/date/projects/duration/attendees) + Action Items + Documents + the body (`MinutesExport.composeMarkdown`) — as a `.md`, or a `.zip` bundling it with `images/`+`docs/` and links rewritten to relative paths when images/documents are present (`Domain/MinutesExport.swift` for the pure pieces; zipping via `NSFileCoordinator` `.forUploading`). **Download PDF** (macOS, `exportPDF()`) exports the same header + Action Items + Documents + body as a **themed PDF that honors each image's `displayWidthPercent`**. It composes an off-screen SwiftUI page (`MinutesExportView`, `Views/ProjectsTab/`) and renders it via **`NSHostingView.dataWithPDF(inside:)`** (single tall page). The body markdown is split into text/image runs by `NotePDFSegments.segments(from:)`: **text** runs render through `PDFMarkdownView` (an `NSTextView` showing `NSAttributedString(html:)` from `MarkdownHTML` wrapped in the palette's CSS — a single CoreText pass, the only thing `dataWithPDF` captures reliably) and **images** through `PDFImageView` (an `NSImageView` framed at `ImageDisplaySize.fit(...)` of the chosen width). The look comes from a selectable `ExportPalette` (`Domain/ExportPalette.swift`: `lightShaded`/`lightPlain`/`dark`, chosen in **Settings ▸ Appearance**, persisted as `AppSettingsStore.pagePalette`) — light palettes use contrast-safe variants of the Kanagawa heading hues (H1 sapphire … H6, matching `MinutesHeadingStyle`), driving both the SwiftUI section headers and the body CSS. **Three renderers were rejected**: `ImageRenderer` won't run Textual's `.task`-based image loading (blank images); a headless `WKWebView`'s content process is throttled here so its navigation never completes (no output); and `NSPrintOperation`/`NSAttributedString`-only output was uncoloured with unhonored image sizes. `dataWithPDF` of a composed view (with `NSImageView` for images, since SwiftUI `Image`/HTML `<img>` don't draw/size into the PDF `CGContext`) is the project's proven note-export mechanism.
